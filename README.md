# ShimmerItemReplace 自定义微光转换

- 作者: 西江小子、羽学
- 出处: TShock官方群816771079
- 这是一个Tshock服务器插件，主要用于：替换微光转换的物品规则

## 指令

| 语法           |        权限         |   说明   |
| -------------- | :-----------------: | :------: |
| /sirc reset | sirc | 重置微光变换为默认值 |
| /sirc load | sirc | 加载配置 |
| /sirc reload | sirc | 重置并加载 |
| /reload | tshock.cfg.reload | 重置并加载 |

## 更新日志

```
v1.2.2
适配TShock 6.1.0 与 泰拉瑞亚1.4.5.6

v1.2.1
加入了自动备注功能,在使用/reload重载配置时自动补充描述
分解配方表暂时失效
```
